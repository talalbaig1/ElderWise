# ElderWise

Staying close, from a distance.

Everyday reassurance for the people who matter most.

## Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS + shadcn/ui
- Framer Motion, Recharts, React Hook Form, Zod, Lucide

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Foundation

This repo currently contains the reusable foundation:

- Design system (light/dark)
- Shared UI components
- Public + authenticated layouts
- TypeScript domain models
- Mock data + localStorage utilities
- Placeholder routes for all product areas

Landing, auth, onboarding, and dashboard experiences will be built in later phases.

## Safety

ElderWise supports family communication and routine monitoring. It is not a substitute for professional medical advice or emergency services.
